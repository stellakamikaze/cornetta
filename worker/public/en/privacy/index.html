What stays on your computer, and what does not.

Recordings and transcripts never leave your computer. The website counts visits without cookies. The app sends a little anonymous usage data, which you can turn off.

Updated 15 October 2026.

Recordings and transcripts

They stay on your computer, in the Music › Cornetta folder. Transcription uses the Mac's own speech recognition and runs on the Mac. Cornetta never sends audio or text to anyone, including its developer.

Website visit statistics

The website uses Plausible, installed on a server run by Federico Nejrotti. Plausible uses no cookies and stores nothing on your device, so there is no banner.

It counts:

  • pages visited and downloads;
  • the site you came from;
  • country, browser and operating system.

Your IP address is only used to compute a code that changes every day, so the same visit is not counted twice. The address is not stored. The data is not shared and not used for advertising.

App usage data

Cornetta sends a short message when one of these things happens:

  • the app opens, or opens after an update;
  • a recording ends: successful or failed, and how long it lasted, in broad ranges (under a minute, 1 to 5 minutes, and so on);
  • a transcription ends: successful or failed.

Each message carries the Cornetta version, the system version, the processor type, the technical code of any error and a random installation number. The country is added by Cloudflare's network, not by the app.

Cornetta never sends audio, text, file names, device names, your contacts or the app you call with. The IP address is not stored.

This data shows whether a new version breaks something, and on which systems, so it can be fixed before you have to report it. It is kept for 12 months, then deleted automatically.

How to turn it off: in the Cornetta menu, untick Invia dati di funzionamento (Send usage data). From then on the app sends nothing and deletes its installation number.

The code that sends this data is public: Mac, Windows, the service that receives it.

Feedback

The Feedback button sends your message only when you press it. Name and email are optional, and technical diagnostics are sent only if you choose them. Feedback is deleted automatically after 90 days.

Updates

At launch and every 4 hours the app checks for a new version by downloading the version list from cornetta.stellakamikaze.org. The request carries only the installed version.

Who handles the data

Cornetta is a personal project by Federico Nejrotti. The website and services run on Cloudflare. Visit statistics run on Federico's own server. For questions or requests use the Feedback button in the app, or open an issue on GitHub.
